FONT TIÊU ĐỀ — UTM Neo Sans Intel
==================================

Hệ thống dùng font "UTM Neo Sans Intel" cho các TIÊU ĐỀ (tiêu đề trang,
tiêu đề đầu mục, số liệu lớn, tiêu đề phiếu in) và font Roboto cho nội dung.

• Nếu MÁY đang xem đã cài sẵn "UTM Neo Sans Intel" → tự dùng luôn.
• Nếu muốn ai mở web cũng thấy đúng font này, hãy đặt file font vào thư mục
  này với đúng tên:
      assets/fonts/UTMNeoSansIntel.woff2   (khuyên dùng — nhẹ, nét)
      assets/fonts/UTMNeoSansIntel.ttf     (tùy chọn)
  Hệ thống đã khai báo @font-face trỏ tới 2 tên file trên.

• Khi CHƯA có file & máy chưa cài: hệ thống tự lùi về "Be Vietnam Pro"
  (tải qua Google Fonts, ĐỦ dấu tiếng Việt) nên tiêu đề vẫn hiển thị đẹp,
  KHÔNG bị lỗi/không mất dấu tiếng Việt.

Lưu ý: UTM Neo Sans Intel là font có bản quyền — vui lòng dùng file font
mà đơn vị bạn đã có quyền sử dụng. Kho mã nguồn này không kèm file font đó.
